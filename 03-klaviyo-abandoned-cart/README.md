# Project 3: Klaviyo Dynamic Abandoned Cart Flow

## 📌 Project Overview
A high-conversion e-commerce automation design. This project focuses on the integration of dynamic data placeholders and e-commerce psychology to recover lost sales.

## 🛠 Technical Features
* **Klaviyo Dynamic Tags:** Implemented Liquid-based syntax (`{{ first_name|default:'there' }}`) for advanced personalization.
* **Dynamic Table Logic:** Structured a product recovery block designed to pull real-time cart data (product image, title, and price) from a Shopify/Klaviyo integration.
* **Conversion-Centric UI:** Utilized a minimalist high-contrast design with clear CTA hierarchy and a "sticky" discount code block.
* **Data-Safe Defaults:** Coded robust "fallback" content for all dynamic tags to ensure a seamless experience even when customer data is incomplete.

## 🚀 Key Learning
Understanding the bridge between developer and marketer. I focused on building a "bulletproof" structure that maintains design integrity even when product titles vary in length or images are missing.
